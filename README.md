# Sitios para Artistas — Catálogo de Servicios

Catálogo de servicios freelance para el diseño y desarrollo de sitios web para músicos y artistas emergentes.

## Contenido

- [`catalogo-es.html`](./catalogo-es.html) — Catálogo en español
- [`catalogo-en.html`](./catalogo-en.html) — Catálogo en inglés

Abrí cualquiera de los dos archivos en el navegador para verlo. También podés convertirlos a PDF desde el navegador (`Imprimir → Guardar como PDF`) si necesitás enviarlos por mail o WhatsApp.
